Nossa equipe

Este projeto é um trabalho academico e tem como objetivo a SEPE do IFC Campus Araquari. A meta deste site é trazer reconhecimento para o Hieróglifo, aprofundar aprendizados a partir de interações e pesquisas. Utilizamos o Figma para fazer Wireframes e os layouts. Também usamos HTML5, CSS3 e JavaScript, editando os códigos no Visual Studio Code.
